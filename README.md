# Automatizacion QA - Preentrega de Proyecto

Preentrega del proyecto de Automatizacion QA. Se busca automatizar flujos basicos de navegacion, en el caso especifico del sitio web saucedemo, el cual esta especialmente desarrollado para practicas de testing. 

## Tecnologias usadas
- Python
- Selenium
- Pytest
- Git
- Github

## Instalacion

Instalar las dependencias:

```python
pip install selenium
```

```python
pip install pytest
```

```python
pip install pytest-html
```

## Ejecutar las pruebas
```python
pytest 
```

## Casos de prueba
- Login exitoso
- Agregar producto al carrito
- Verificar producto agregado al carrito
